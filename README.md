# gibarberi-web

Sitio de **Gi. Barberi** · Diseño, marketing y SEO.

Sitio estático (HTML, CSS y JS), publicado en Cloudflare Pages. No necesita compilación.

- `index.html`: la página
- `llms.txt`: información del estudio para asistentes de IA
- `robots.txt` y `sitemap.xml`: SEO
- `_headers`: encabezados de seguridad
- `og.png`: imagen para compartir el link en redes
